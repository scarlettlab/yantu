# 研途

研途是一套帮助药物研发人员使用 AI 完成工作的技能和工具。你可以用它查文献、调研临床试验、比较方案、核对数据，以及起草医学文稿和项目邮件。

它主要服务药物研发中的临床研究医生和研发团队。六个技能可以分别安装，也可以通过插件一起使用。

**版本：1.0.0（研途 V1.0）。**

## 我应该用哪个技能？

| 技能 | 帮你做什么 | 示例 |
|---|---|---|
| [研途Atlas](skills/yantu-atlas/README.md) | 查文献和指南，整理证据 | “这个终点有哪些研究依据？” |
| [研途Scout](skills/yantu-scout/README.md) | 系统调研试验、开发路径和竞争格局 | “这个药在某适应症做过哪些试验？” |
| [研途Guide](skills/yantu-guide/README.md) | 比较方案和开发策略，给出建议 | “这两套入组标准，哪套更适合本项目？” |
| [研途Trace](skills/yantu-trace/README.md) | 整理数据，核对表格和计算 | “两张表的分母和结果为什么不同？” |
| [研途Frame](skills/yantu-frame/README.md) | 整理邮件、沟通内容和会议记录 | “把这些结论写成项目组英文邮件。” |
| [研途Draft](skills/yantu-draft/README.md) | 起草、修改和检查正式文稿 | “根据这些材料起草方案背景。” |

## 怎样开始？

1. **安装。** 需要某个技能，就下载并解压对应的单技能包；需要全部六个，就使用整套插件包。具体操作见[安装说明](docs/INSTALL.md)。
2. **告诉 AI 你的任务。** 说明研究对象、当前问题、已有资料和希望得到的结果。
3. **查看结果与来源。** 研途会整理内容、注明依据，并列出尚未核实的信息。

例如：

> 用研途Scout 梳理 semaglutide 在肥胖适应症的临床开发路径，整理关键试验、主要终点以及疗效和安全性结果，说明哪些信息还需要补查。

如果下载的是整个源码目录，可在该目录运行以下命令安装 Scout（需要 Python 3.9+）：

```sh
python3 scripts/install_skills.py --skill scout
```

安装全部技能使用 `--all`。默认安装目录为 `~/.agents/skills/`；已有同名目录时安装器会停止。

## Scout 怎样读取临床试验数据？

如果 AI 能运行 Python 并访问 ClinicalTrials.gov，Scout 会用随包脚本直接读取官方 API，支持连续翻页、研究详情和结果数据。这一步可以交给 AI 完成，不需要 API key。

如果当前 AI 无法直接访问 API，可以使用兼容的 MCP 连接。MCP 在这里是一条让 AI 读取注册库数据的连接方式，需要时再配置，见[连接说明](optional-mcp/README.md)。

只有网页或已有资料可用时，Scout 会说明已读范围和还缺哪些信息。默认累计读取 200 条候选记录后确认是否继续；用户明确要求全量时可以继续。候选记录取完后，仍需要筛选、核对和分析。

## 使用前准备什么？

- 使用支持技能或相应插件格式的 AI 平台。查外部资料需要联网；运行脚本和生成 Office 文件需要平台提供相应工具。
- 提供与任务有关的项目材料、数据或模板。精确分级、术语编码和监管要求，需要使用项目适用的资料版本。
- 研途提供研发分析和建议，重要结论应由专业人员核实后用于实际项目。
