# 研途Guide

**比较方案，形成研发建议。** 研途Guide 帮你分析入组人群、剂量、安全性、方案设计和研究执行中的选择。

适用于药物临床研发，可单独安装，也可随研途插件一起使用。

## 开始使用

1. 解压单技能包，将整个 `yantu-guide/` 文件夹放入客户端的技能目录。Codex 用户目录为 `~/.agents/skills/`，其他客户端按其说明设置。
2. 按客户端要求刷新技能或开启新会话。已有同名技能时，先保存自己的修改并处理旧版本。
3. 选择研途Guide；支持名称调用的客户端可输入 `$yantu-guide`。例如：

> 用研途Guide 比较这两套入组标准，说明对研究结果和入组可行性的影响，并给出建议。

## 提供什么，会得到什么？

**你提供：** 开发目标、正在比较的选项、项目资料，以及时间、资源等实际限制。

**你得到：** 选项比较、推荐理由、影响判断的不确定因素和下一步建议。

查外部资料需要 AI 有相应检索工具；生成文件或运行计算需要平台提供相应工具。重要结论请核实后用于实际项目。

## 文件说明

- `README.md`：给使用者看的说明。
- `SKILL.md`：告诉 AI 什么时候使用本技能、怎样完成任务。
- `agents/openai.yaml`：设置客户端中显示的名称、简介和默认提问。
- `LICENSE`：使用许可，随单技能包附带。
- `THIRD_PARTY_NOTICES.md`：所用工具、外部资料和第三方许可的说明，随单技能包附带。
