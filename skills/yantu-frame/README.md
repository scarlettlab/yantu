# 研途Frame

**把已有结论写成清楚的沟通内容。** 研途Frame 帮你把事实、判断和行动项整理成邮件、会议记录或中英文沟通文字。

适用于药物临床研发，可单独安装，也可随研途插件一起使用。

## 开始使用

1. 解压单技能包，将整个 `yantu-frame/` 文件夹放入客户端的技能目录。Codex 用户目录为 `~/.agents/skills/`，其他客户端按其说明设置。
2. 按客户端要求刷新技能或开启新会话。已有同名技能时，先保存自己的修改并处理旧版本。
3. 选择研途Frame；支持名称调用的客户端可输入 `$yantu-frame`。例如：

> 用研途Frame 把这些已确认结论写成项目组英文邮件，明确待决事项和下一步。

## 提供什么，会得到什么？

**你提供：** 沟通对象、目的、已确定的结论和希望采用的语气。

**你得到：** 可以直接修改使用的正文，以及需要确认的事项和下一步行动。

查外部资料需要 AI 有相应检索工具；生成文件或运行计算需要平台提供相应工具。重要结论请核实后用于实际项目。

## 文件说明

- `README.md`：给使用者看的说明。
- `SKILL.md`：告诉 AI 什么时候使用本技能、怎样完成任务。
- `agents/openai.yaml`：设置客户端中显示的名称、简介和默认提问。
- `LICENSE`：使用许可，随单技能包附带。
- `THIRD_PARTY_NOTICES.md`：所用工具、外部资料和第三方许可的说明，随单技能包附带。
