# 研途Scout

研途Scout 帮你系统调研临床试验、药物开发路径，以及某个靶点或疾病的竞争格局。它会查找研究、核对设计和结果、比较资料中的差异，并列出需要继续补查的信息。

适用于药物临床研发，可单独安装，也可随研途插件一起使用。

## 可以做哪几类调研？

| 模式 | 适合的任务 |
|---|---|
| A 全面扫描 | 围绕明确的研发问题，整理多个方面的证据 |
| B 试验深挖 | 详细整理某项或某几项试验的设计、人群、分组、终点和结果 |
| C 开发路径复盘 | 按时间和研究阶段，重建一个药物的开发过程 |
| D 靶点格局扫描 | 梳理同一靶点下的项目、药物和关键试验 |
| E 疾病研发扫描 | 梳理某个疾病领域的研发方向和主要竞品 |

普通文献问题可以使用 Atlas。需要上表中的系统调研时，再使用 Scout。

## 开始使用

1. 解压单技能包，将整个 `yantu-scout/` 文件夹放入客户端技能目录。Codex 用户目录为 `~/.agents/skills/`；其他客户端按其说明设置。
2. 刷新技能或开启新会话，选择研途Scout；支持名称调用时可输入 `$yantu-scout`。
3. 告诉 AI 调研对象、适应症、范围，以及希望得到报告还是表格。例如：

> 用研途Scout 梳理 semaglutide 在肥胖适应症的开发路径。整理关键试验、主要终点、疗效和安全性结果，注明来源和还需要核实的信息。

已有同名技能时，先保存自己的修改并处理旧版本。在同一客户端中使用一个版本的研途即可。

## 它怎样查数据？

能运行 Python 并访问 ClinicalTrials.gov 时，Scout 用随包脚本直接读取官方 API，包括连续翻页和单项研究结果。Python 3.9+ 即可，不需要 API key；执行脚本可以交给 AI。

不能直连时，可使用已配置的兼容 MCP 连接。只有网页或已有资料可用时，就在这些资料范围内调研，并说明还缺什么。

默认累计取回 200 条候选记录后确认是否继续。需要全量时可在任务中明确提出；取得所有候选后，仍需要核对、筛选和分析。

## 文件夹中每个文件做什么？

下面列出单技能包中的全部 17 个文件。通常先看 README，再由 AI 按任务读取规则或调用工具。

| 文件 | 用途 |
|---|---|
| `README.md` | 使用方法、任务示例和文件用途，即本页 |
| `SKILL.md` | Scout 的完整主规则：何时启用、五种模式及输出、三轮检索、证据核查、取数、交付和最终核对 |
| `agents/openai.yaml` | 设置客户端显示的名称、简介和默认提问 |
| `references/general-rules-v3.6.1.txt` | 证据分类、来源说明、日期、样本量、引用和核查要求 |
| `references/trial-modes-v3.6.1.txt` | B/C 模式的字段、研究阶段、检索方法和表格要求，也含 D 模式的检索补充 |
| `references/landscape-modes-v3.6.1.txt` | D/E 模式的竞品选择、输出字段、疗效与安全性数据要求 |
| `references/clinicaltrials-api-v3.6.1.txt` | ClinicalTrials 数据字段对照、日期处理和其他来源补查方法 |
| `references/data-access.md` | 选择直连或 MCP，如何运行脚本、翻页、续取，以及怎样记录失败和完成范围 |
| `references/mcp-workflow-v0.2.1.md` | 使用 MCP 时的调用参数、研究模块和续页方法 |
| `references/excel-delivery-v3.6.4.md` | Excel 的字段完整性、样式、冻结、筛选和来源链接要求 |
| `scripts/clinicaltrials.py` | 实际访问官方 API：小样本检查、搜索、翻页和读取单项研究；保存原始响应及取数报告 |
| `scripts/clinicaltrials_fields.py` | 上述脚本调用的辅助模块，从研究 JSON 中提取指定部分，保留组别、分母和结果字段；需与主脚本放在同一目录 |
| `scripts/build_excel_report.mjs` | 将结构化数据生成 Excel；在提供所需运行库的环境中使用，也可由平台其他表格工具完成同一交付 |
| `scripts/validate_excel_delivery.py` | 检查生成的 Excel 文件结构、冻结、筛选、格式和来源链接；医学内容另行核对 |
| `examples/excel-style-sample.json` | 虚构数据，用来演示 Excel 的输入格式和样式 |
| `LICENSE` | 使用许可，随单技能包附带 |
| `THIRD_PARTY_NOTICES.md` | 外部资料和工具适用的第三方许可说明，随单技能包附带 |
