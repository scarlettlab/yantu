# 研途Draft｜证据与引用参考（V0.7）

更新日期：2026-09-27  
来源：整理自本目录 V0.4《证据与引用规范》，按主提示词 V0.7 的“本轮已核实”与正文压缩风险要求修订。  
用途：提供证据提取字段、主张匹配示例和引用格式参考。执行门槛以当前主提示词为准；本文件不含可直接引用的医学或监管结论，也不能代替打开原始来源。

## 1. 按主张类型选直接来源

| 待支持的主张 | 优先核对的来源 | 容易发生的错配 |
|---|---|---|
| 某项目的设计、剂量、分析集或结果 | 当前正式方案、SAP、数据库/TLF、CSR 等相应原件 | 用旧方案、注册摘要或二手解读代替当前项目文件。 |
| 某研究的疗效或安全性结果 | 原始研究正式发表内容、正式研究报告或可核实的原始结果 | 将摘要中的方向性结果扩写成具体数值或未报告的亚组结论。 |
| 疾病背景、流行病学或治疗现状 | 与人群、地区、时期和定义相符的原始研究或高质量综合证据；机构自行发布的统计以其原始报告为准 | “权威”但统计口径不同，或用综述支撑原研究特定结果。 |
| 监管要求、文件状态或时限 | 当前适用地区的官方法规、指导原则、问答或办事页面原文 | 将草案写成生效要求，或把一个地区的要求套到另一地区。 |
| 作者的机制解释或综合判断 | 与机制、人群和研究场景相关的直接证据，并明确解释与观察的差别 | 把作者假设写成试验已证明的结果。 |

来源的顺序由具体主张决定，不存在适用于所有问题的固定证据等级表。检索入口、旧 Knowledge 文件和模型记忆都不是当前版本或实际结果的证明。

## 2. 主张级提取卡

正式证据核查可按以下字段记录；局部语言润色无需输出整张卡。

| 字段 | 记录内容 |
|---|---|
| 主张 | 当前要支持的完整句子；含人群、干预/暴露、对照、终点、时间点及结论强度。 |
| 来源身份 | 文件/论文题名、作者或机构、发表/发布状态、版本、日期、实际打开位置。 |
| 原始信息 | 原文条款或结果、页码/章节/表图、人数与分母、效应量及不确定性。 |
| 匹配性 | 人群、剂量、比较、终点、访视、分析集和地区是否相符。 |
| 证据状态 | 直接支持、仅背景、间接支持、需要外推、无法核实、与主张冲突。 |
| 写作决定 | 保留完整限定、降低结论强度、删除数字、换更直接来源或标记待核。 |

监管核查另补：发布机构、法律/规章/指导原则/问答类别、现行状态、生效日期、适用地区与产品类型、直接相关条款及原文的约束强度。

## 3. “已核实”不等于“可写入正文”

| 情况 | 处理示例 |
|---|---|
| 来源确有数字，但定义与当前句子的对象不同 | 不沿用该数字；改写主张或寻找定义匹配的来源。 |
| 来源支持完整且复杂的限定条件，正文无法安全压缩 | 保留必要限定；若当前章节不适合展开，删除该数字。 |
| 只打开摘要或搜索结果，未核对承载主张的原始内容 | 不给成型引用；使用【引用待核】并指出需核的结果/条款。 |
| 来源仅支持方向，未支持因果、长期获益或临床决策价值 | 只写观察方向；更强结论标为【证据待补】。 |
| 官方文件存在“建议、可考虑、通常”等措辞 | 引文按原文约束强度表达，不升级为强制义务。 |

示意：如果某研究报告的是【亚组A在第X周的指标变化】，正文不得压成“该药对所有患者长期有效”。该例完全是假设性写作演示，不代表任何药物事实。

## 4. 引用呈现示例（均为占位格式，不是文献）

**正文：**在【指定人群】中，【指定终点】于【时间点】观察到【实际结果】[1]。对更广泛人群的适用性仍需【证据待补】。

**本段已核实引用**

1. 【作者/机构】. 【实际核实题名】. 【实际核实期刊/文件名】. 【实际核实年份、卷期页或版本】。

**待核实/待补证据**

- 【证据待补】需要直接支持“【外推主张】”的来源。

同一来源再次使用时沿用同一编号。书目信息只填写本轮实际可见且核对过的字段；卷期页、DOI、PMID 缺失时留空，不按常见格式猜填。网页来源只有在本轮实际打开具体页面并核对主张时，才记录该页面 URL 与实际访问日期。网页发布日期不能充当访问日期。实际引用正式 PDF 时，按该文件的可核实版本和页码记录；不要以机构首页代替实际内容页。

## 5. 局部写作的简化口径

- 纯语言润色：保留原意，不凭空加文献；若原文事实明显矛盾，指出问题。
- 带外部主张的局部起草：核实关键主张后给 `[n]`；无法核实处单独标【引用待核】或【证据待补】。
- 正式证据综述：保存检索日期、数据库/网站、检索式、筛选条件和关键排除理由；结果围绕问题综合，不逐篇堆叠。
- 监管核查：逐项记录文件状态和适用边界；无法确认版本或条款时标【监管依据待核】。
