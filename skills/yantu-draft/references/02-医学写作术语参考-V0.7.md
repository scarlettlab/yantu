# 研途Draft｜医学写作术语参考（V0.7）

更新日期：2026-09-27  
来源：整理自本目录 V0.2《医学写作术语表》，按主提示词 V0.7 的场景语言要求修订。  
用途：供写作时查询易混术语及表达场景；不是官方术语库、项目术语表或医学事实来源。项目方案、SAP、TLF、公司模板和用户指定用词应逐项核对。本文件不用于证明法规版本、临床结果或文献结论。

## 1. 研究对象、设计和分析

| 英文或概念 | 常用中文 | 需要区分的边界 |
|---|---|---|
| clinical study / clinical trial | 临床研究 / 临床试验 | 前者范围较宽；具体文件按研究类型和正式标题定名。 |
| participant / subject / patient | 研究参与者 / 受试者 / 患者 | 临床试验文件常用“受试者”；诊疗语境常用“患者”；健康受试者不称“患者”。 |
| study population / target population / analysis population | 研究人群 / 目标人群 / 分析人群 | 实际入组、结论拟适用和用于某项分析的人群不可互换。 |
| open-label / single-arm | 开放标签 / 单臂 | 是否设盲与是否设置对照臂是不同维度。 |
| comparator / standard of care | 对照 / 标准治疗 | 对照的具体构成及当地标准治疗以方案和适用场景为准。 |
| objective / endpoint / outcome | 研究目的 / 终点 / 结局 | 目的描述问题；终点应落实到变量、测量与时间点；“结局”不自动等于方案终点。 |
| estimand / intercurrent event | 估计目标 / 伴发事件 | 估计目标不是统计方法；伴发事件及处理策略应依据当前方案和 SAP 明确定义。 |
| ITT / FAS / PPS / safety set | 意向性治疗人群 / 全分析集 / 符合方案集 / 安全性分析集 | 名称相近不代表定义相同；纳入条件和缩写以项目 SAP 为准。 |
| primary / secondary / exploratory endpoint | 主要 / 次要 / 探索性终点 | 报告层级、统计控制和结论强度需与设计一致。 |
| baseline | 基线 | 随机分层、疗效变化和安全性描述可能采用不同访视或日期；写明指标与时间锚点。 |

## 2. 统计与结论表达

| 英文或概念 | 常用中文 | 需要区分的边界 |
|---|---|---|
| effect estimate | 效应估计值 | 指明比较、方向、分析人群和时间点。 |
| confidence interval / SD / SE | 置信区间 / 标准差 / 标准误 | CI 应标明置信水平；SD 描述离散，SE 描述估计的不确定性。 |
| statistical significance / clinical relevance | 统计学显著性 / 临床意义 | 前者不能自动推出后者；临床意义需看效应大小、结局及适用情境。 |
| sensitivity / supplementary / subgroup / post hoc analysis | 敏感性 / 补充 / 亚组 / 事后分析 | 目的及预设状态不同；不把事后分析写成方案预设。 |
| association / causal effect | 相关性 / 因果效应 | 观察到关联不直接证明因果；措辞随研究设计和假设调整。 |
| observed result / interpretation / hypothesis | 观察结果 / 解释 / 假设 | 结果段写实际指标与变化；讨论段再提出受证据限制的解释。 |

## 3. 安全性与临床叙述

| 英文或概念 | 常用中文 | 需要区分的边界 |
|---|---|---|
| AE / TEAE / ADR | 不良事件 / 治疗期间出现的不良事件 / 药物不良反应 | TEAE 时间窗、ADR 因果判断均以当前项目定义和适用语境为准；AE 不自动代表药物相关。 |
| SAE / severity | 严重不良事件 / 严重程度 | “严重性”判定与轻、中、重“严重程度”分别描述。 |
| causality / expectedness | 因果关系 / 预期性 | 判断主体、参照文件及用词依项目和地区要求确认。 |
| AESI | 特别关注的不良事件 | 事件范围和识别规则以方案及安全性文件为准。 |
| action taken / outcome / exposure | 对研究药采取的措施 / 转归 / 暴露 | 分别记录暂停、减量等措施、事件结局及剂量和持续时间；不要互相替代。 |
| benefit–risk | 获益—风险 | 综合可支持的获益、已识别风险、重要不确定性和目标人群。 |

## 4. 常见文件名及场景

| 缩写 | 常用名称 | 写作时核对点 |
|---|---|---|
| CSP / protocol | 临床试验方案 | 版本、入排、剂量、访视、终点与方案修订。 |
| IB | 研究者手册 | 当前版本、非临床与临床证据、安全性资料。 |
| SAP | 统计分析计划 | 分析集、估计目标、缺失数据、统计模型。 |
| CSR | 临床研究报告 | 方案、SAP、数据库和表图列的一致性。 |
| CTD 2.5 / 2.7 | 临床综述 / 临床总结 | 总体判断与资料汇总的功能不同；按适用申报要求核对。 |
| ISE / ISS | 综合有效性总结 / 综合安全性总结 | 使用位置和内容按适用地区与申报类型核对，不与 CTD 小节机械画等号。 |

## 5. 语境与表达示例

- 疾病定义可使用病理生理描述；转入治疗或管理语境时，应落到实际干预目标和临床结局。例如讨论肥胖长期管理，写“减重、维持体重改善、降低相关并发症风险”通常比重复“控制脂肪蓄积”更贴近管理场景。此例只说明表达层级，不构成疗效主张。
- 结果写“第【时间点】的【指标】由【数值】变为【数值】”；“代谢改善”属于综合解释，须看实际指标和证据是否支持。
- 比较安全性时，先锁定人数分母、观察时间、治疗暴露和事件口径；不能为了语言变化轮换“AE”“ADR”“TEAE”。
