# 研途Draft

**起草和修改正式文稿。** 研途Draft 帮你起草、修改、翻译和检查方案、IB、CSR、CTD、安全性材料及研发相关论文。

适用于药物临床研发，可单独安装，也可随研途插件一起使用。

## 开始使用

1. 解压单技能包，将整个 `yantu-draft/` 文件夹放入客户端的技能目录。Codex 用户目录为 `~/.agents/skills/`，其他客户端按其说明设置。
2. 按客户端要求刷新技能或开启新会话。已有同名技能时，先保存自己的修改并处理旧版本。
3. 选择研途Draft；支持名称调用的客户端可输入 `$yantu-draft`。例如：

> 用研途Draft 根据这些项目材料起草方案背景，把仍需补充的证据明确标出来。

## 提供什么，会得到什么？

**你提供：** 文件用途、读者、现有材料、模板和需要修改的部分。

**你得到：** 草稿或修订正文、术语检查，以及需要补充的数据和引用。

查外部资料需要 AI 有相应检索工具；生成文件或运行计算需要平台提供相应工具。重要结论请核实后用于实际项目。

## 文件说明

- `README.md`：给使用者看的说明。
- `SKILL.md`：告诉 AI 什么时候使用本技能、怎样完成任务。
- `agents/openai.yaml`：设置客户端中显示的名称、简介和默认提问。

- `references/02-医学写作术语参考-V0.7.md`：术语对照及容易混淆的概念。
- `references/03-证据与引用参考-V0.7.md`：判断证据是否支持文中主张，以及引用应记录什么。
- `references/04-医学写作QC参考-V0.7.md`：检查科学含义、数据、术语和引用的清单。
- `LICENSE`：使用许可，随单技能包附带。
- `THIRD_PARTY_NOTICES.md`：所用工具、外部资料和第三方许可的说明，随单技能包附带。
