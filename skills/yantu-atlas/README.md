# 研途Atlas

**查找和整理研发证据。** 研途Atlas 帮你检索文献和指南，比较研究结果，说明证据能支持什么、还缺什么。

适用于药物临床研发，可单独安装，也可随研途插件一起使用。

## 开始使用

1. 解压单技能包，将整个 `yantu-atlas/` 文件夹放入客户端的技能目录。Codex 用户目录为 `~/.agents/skills/`，其他客户端按其说明设置。
2. 按客户端要求刷新技能或开启新会话。已有同名技能时，先保存自己的修改并处理旧版本。
3. 选择研途Atlas；支持名称调用的客户端可输入 `$yantu-atlas`。例如：

> 用研途Atlas 整理某个临床终点在目标人群中的证据，区分研究结果与指南建议，给出来源。

## 提供什么，会得到什么？

**你提供：** 研究问题、目标人群，以及你关心的终点、机制或研究设计。

**你得到：** 文献与指南摘要、来源链接、研究间的差异和证据缺口。

查外部资料需要 AI 有相应检索工具；生成文件或运行计算需要平台提供相应工具。重要结论请核实后用于实际项目。

## 文件说明

- `README.md`：给使用者看的说明。
- `SKILL.md`：告诉 AI 什么时候使用本技能、怎样完成任务。
- `agents/openai.yaml`：设置客户端中显示的名称、简介和默认提问。
- `LICENSE`：使用许可，随单技能包附带。
- `THIRD_PARTY_NOTICES.md`：所用工具、外部资料和第三方许可的说明，随单技能包附带。
