# 使用许可说明

研途采用 **研途个人与内部使用许可 1.0**。下表帮助你判断常见用途；完整条件以仓库或分发包中的 [LICENSE](../LICENSE) 为准。

| 使用情形 | 是否允许 |
|---|---|
| 为自己的学习、研究和工作使用研途 | 允许 |
| 在公司内部使用，或修改成适合内部工作流程的版本 | 允许，包括营利组织 |
| 对外提交、发表或商业使用借助研途完成的报告、论文、分析等普通工作成果 | 允许，相关输入与外部资料仍须遵守适用条款 |
| 将研途原版或修改版重新打包，免费或收费向组织外分发 | 需另行书面授权，平台条款及法律允许的情形除外 |
| 将研途原版或修改版作为给别人使用的产品、订阅功能、技能包或线上服务的一部分 | 需另行书面授权 |
| 使用 GitHub 功能查看或站内 fork | 适用 GitHub 平台授予的相应权利 |

## 公司内部使用与对外产品有什么区别？

公司的研发团队将研途用于内部文献调研、方案讨论或数据核查，属于允许的内部使用。把修改后的研途嵌入对外提供的 AI 助手、技能商城或订阅产品，需要另外取得授权。

## 工作成果可以对外使用吗？

可以。使用研途完成的报告、论文、表格和其他正常工作成果，可以按适用要求对外提交、发表或商业使用，也不需要因此沿用研途的许可。如果交付给别人的内容包含研途的提示词、代码或修改版，这属于分发研途材料，需要按再分发条款处理。

## 修改后需要做什么？

保留项目副本中的许可、版权和第三方声明，记录修改，并避免暗示获得原作者背书。正常工作产出不要求逐份标注使用了研途。

## Fork 是否代表可以任意再分发？

站内 fork 适用 GitHub 平台规则。它本身不额外授予在其他地方再分发、授权给第三方使用，或做成对外产品的权利；这些用途仍需按 LICENSE 判断。

## 怎样申请其他授权？

通过来源仓库标示的联系渠道或 Issue 说明拟使用的内容、面向对象和分发方式，取得明确书面授权后再实施。未收到回复不表示同意。

本项目公开源码，但许可包含对外分发和产品化限制，因此不属于 OSI 开源许可。第三方库、外部资料和数据适用各自条款，见[第三方声明](../THIRD_PARTY_NOTICES.md)。
