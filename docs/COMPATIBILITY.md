# 环境要求与兼容性

能否完成任务取决于当前会话的工具、执行权限和网络能力。仅凭“网页端”或“桌面端”名称，无法判断是否能运行脚本或读取完整 API 分页。

## 按任务检查能力

| 任务 | 所需能力 | 能力不足时 |
|---|---|---|
| 整理给定材料、沟通和文字起草 | 读取技能与用户资料 | 根据可见材料回答，标记缺失信息 |
| 查询外部文献、指南和监管资料 | 可访问相应来源的检索工具 | 标明哪些来源无法核实 |
| Scout 直连 ClinicalTrials.gov | Python 3.9+、HTTPS 网络、文件读写 | 使用已配置的兼容 MCP，或在可访问资料范围内调研 |
| Scout 使用 MCP | 客户端支持 MCP 且连接可用 | 使用已验证的直连脚本或限定资料范围 |
| 输出 Word、Excel 等文件 | 相应文档工具或运行库 | 提供可用的结构化内容，明确文件交付限制 |

安装技能不会改变平台的联网或执行权限。使用已有的账号设置和管理员授权；直连脚本沿用执行环境的网络设置。

## 已有测试证据

| 被测环境与组件 | 观察结果 | 证据边界 |
|---|---|---|
| 本地 Python 3.12.13，直连脚本 0.1.0-rc.1 | 两页及详情、结果模块读取成功，4 次请求 HTTP 200 | 小样本验证；不代表所有网络环境 |
| ChatGPT Work 网页，早期直连原型 0.1.0 | 2026-10-05 测试报告记录两页及详情成功；semaglutide 连续 8 页、769 条、到末页 | 报告级证据，未独立复算该报告的原始响应；只覆盖被测会话与查询 |
| ChatGPT Chat 网页，同一原型 | 2026-10-05 测试报告记录脚本可运行，但 DNS 解析失败 | 只覆盖被测会话；不能由此认定所有 Chat 会话均失败 |
| 1.0.0 发行包 | 沿用相同直连脚本和 MCP 代码；Scout 主规则整合到 SKILL.md | 具体检查及待验证项目见验证状态 |

Work 的代码联网能力还可能受账号和管理员设置控制；如账号提供对应入口，可查阅 [Work 网络权限说明](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-overview#network-access-and-external-destinations)。

建议先在所用环境运行 Scout 的小样本 probe，再开展大规模取数。检查成功后也需要保留分页状态、缺失字段和实际完成范围。
