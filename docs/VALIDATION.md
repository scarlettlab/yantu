# 验证状态

发行版本：**1.0.0**。记录日期：2026-10-05。

## 文件与分发包

本版将 Scout 主规则与已有补充要求统一到 SKILL.md，按八部分组织；保留原有细节与措辞，旧主规则不再重复分发。核对原文各项规则、补充要求及参考文件引用。名称为研途，安装目录使用 yantu 前缀，Scout 单技能包包含 17 个文件。对分发包检查资源引用、内部文档链接、语法和清单、ZIP 完整性及成员内容，并生成 SHA256SUMS.txt。八个包分别解压核对，六个独立技能均包含 README、入口、所需资源和许可声明。

独立安装器已验证可复制六技能，并在目标存在时拒绝覆盖。源目录中的系统浏览元数据和 Python 缓存不进入分发包。
